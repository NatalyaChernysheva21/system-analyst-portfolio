# STETS — система управления умным домом

## Описание проекта

STETS — мобильное приложение для управления системой умного дома.

Система предусматривает работу с учетной записью пользователя, создание и настройку дома, управление комнатами и устройствами, настройку прав доступа участников и создание сценариев автоматизации.

## Цель проекта

Спроектировать основные функции системы управления умным домом и подготовить аналитическую документацию для их реализации и проверки.

## Выполненные задачи

- сформированы User Stories и критерии приемки;
- описаны позитивные и альтернативные сценарии;
- разработана контекстная DFD;
- разработана DFD Level 1;
- спроектирована логическая ER-модель данных;
- подготовлена программа и методика испытаний.
